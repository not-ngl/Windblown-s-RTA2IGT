# Windblown-s-RTA2IGT
A CLI project to assist SRC moderation to remove loading time from run submission.

Currently only works for linux with nomacs, and the python dependencies numpy, ffmpeg-pytohn and yt-dlp.

## What's the logic
Using a local file (or an URL) and providing timestamp INSIDE loading, the tool expands the entire load region automatically. A second pass with quick navigation allows to adjust all of the to the frame without needing to open an editor software.

## Usage
An example is provided with the link of a run and the preset values for the time stamps.
